# 图书馆 RFID 盘点工具

馆员使用手持 RFID 设备扫描书架后，系统自动比对馆藏记录，产出分层盘点报告与错架整理清单。

## 快速开始

无需安装依赖，直接用浏览器打开 `index.html` 即可（或任意静态服务器托管）。

1. **选择盘点范围**（全部 / 指定楼层 / 指定书库），点击「开始模拟盘点」
   - 实际部署时，此处替换为手持设备扫描数据（RFID + 架位）的导入接口
2. **总览仪表盘**：盘点条目、正常在架、错架、缺失、借出/修补、未登记标签、在架准确率
3. **分层浏览**：按 `楼层 → 书库 → 分类号` 三级折叠查看，每级节点带统计徽标，明细表只展开需要的节点，避免面对一张长表格
4. **错架整理清单**：
   - 「按当前位置分组」→ 馆员按清单到架取书
   - 「按应归架位分组」→ 按目标架位归位上架
   - 标注错架层级（架位 / 书库 / 楼层），支持导出 CSV 与打印
5. **缺失清单**：状态为「在馆」但未扫到的图书，按楼层分组，可导出 / 打印

## 比对规则

| 类别 | 判定 |
|---|---|
| 正常在架 | 扫到且 楼层/书库/架位 与馆藏记录一致 |
| 错架 | 扫到但位置不符，按偏差分为架位级 / 书库级 / 楼层级 |
| 缺失 | 馆藏状态为「在馆」但本次未扫到 |
| 借出/修补 | 未扫到但流通状态可解释，不计入异常 |
| 未登记 | 扫到但系统无此 RFID 记录（外来图书 / 标签未关联） |

## 目录结构

```
rfid-inventory/
├── index.html      页面结构
├── css/style.css   样式
└── js/
    ├── data.js     馆藏数据模型、示例数据生成、扫描模拟
    ├── compare.js  比对引擎、分层统计、整理清单、CSV 导出
    └── app.js      页面渲染与交互
```

## 对接真实设备

将 `simulateScan()` 替换为实际数据导入即可，扫描记录格式：

```json
{ "rfid": "E0040100000001", "floor": "2F", "room": "科技借阅区", "shelf": "TP03", "time": "2026-09-15T09:30:00Z" }
```

比对、分层、清单、导出逻辑均无需改动。
